# 🍳 Recipe Finder App

A responsive Recipe Finder web application built for Task 14 of the Web Development Internship.

The application allows users to search for recipes by name or ingredient and view detailed recipe information.

## 🚀 Features

- Search recipes by name
- Search recipes by ingredient
- Debounced search input
- Recipe results grid
- Recipe detail modal
- Ingredients list
- Cooking instructions
- Recipe category
- Recipe area/cuisine
- YouTube recipe video link
- Loading states
- Error handling
- No-results handling
- Responsive design
- Mobile-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- TheMealDB API

## 🌐 API

This project uses the public TheMealDB API.

API endpoints used:

- Search by name
- Search by ingredient
- Get recipe details

## ▶️ How to Run

Clone the repository:

git clone https://github.com/Abhinav1574k/recipe-finder.git

Open the project folder:

cd recipe-finder

The application can be opened directly through index.html or served using a local development server.

For example:

npx serve .


## 🔎 Usage
Enter a recipe name or ingredient.
Select the search type.
Search for recipes.
Browse the results.
Click View Recipe.
Review ingredients and cooking instructions.
